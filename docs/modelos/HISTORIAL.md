# Historial de versiones — Diagramas PGIM

Metodología: una **versión nueva** (carpeta `vN`) cuando hay un cambio mayor (clase o tabla nueva). Un **cambio menor** (formato, atributos, tipos de datos) reemplaza el archivo de la última versión.
Cada versión incluye la imagen (`.png`) y su fuente editable: `.mmd` (Mermaid) para clases y DER; `.puml` (PlantUML) para casos de uso, secuencia, wireframes y el diagrama de clases unificado. Desde el 29/09 los diagramas nuevos se hacen en PlantUML.
